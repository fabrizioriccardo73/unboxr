Features

Built for the archives other free apps give up on

Split in parts, several gigabytes large, years old or half broken: Unboxr handles them, on the 7-Zip extraction engine.

📂

Browse before extracting

See what is inside an archive, sort it, and decide what you need without extracting a single byte.

🎯

Extract only what you need

Select files or whole folders and extract or share just those.

👁️

Quick Look

Preview text and code, images, audio and PDFs straight from the archive.

🧩

Split archives

Open .part1.rar, .7z.001 and .z01 sets. If a part is missing, Unboxr tells you which one before it starts.

🛡️

Verify integrity

Test a download against its checksums without extracting it. You get a clear verdict, or the list of damaged files.

🔎

Search inside the archive

Search by name, ignoring case and accents, and filter by type: images, videos, documents, code and more.

🩹

Damaged archives

One broken file no longer stops everything. The intact files are extracted, and you are told which ones were not.

⚡

Instant opening

Archives are read in place, with no preliminary copy. Multi-gigabyte files open at once and need no extra free space.

🔐

Password-protected archives

Open encrypted archives, and retry a wrong password without starting over.

🔤

Readable names in old ZIPs

Garbled file names from old Windows, Cyrillic, Japanese, Chinese or Korean archives are fixed automatically, with 23 encodings to pick by hand.

✋

No surprise overwrites

When a file already exists you choose: keep both, skip or overwrite. Extractions can be stopped, and partial files are cleaned up.

📦

XAPK and split APK installer

Install apps and games shipped as XAPK, APKM or split APKs, OBB data included.

Also in the app: open archives from another app's share sheet, drag and drop on tablets and foldables, launcher shortcuts, and Silicon Speed Test, a CPU benchmark built on the 7-Zip LZMA engine.

Privacy

FAQ

Questions

Is Unboxr really free?

Yes. Every feature is available to everyone. There is no Pro version, no in-app purchase, no subscription and no advertising. If you find it useful you can leave a tip on Ko-fi, which unlocks nothing.

Can it open password-protected RAR and 7Z files?

Yes. Unboxr asks for the password when the archive needs one, and lets you try again if you get it wrong.

Can it open archives split into several parts?

Yes. Select one part, tap "Add parts" and pick the others, or share them to Unboxr all together. It then browses and extracts the set like a single archive.

Can I create ZIP or 7Z archives with it?

Not yet. Unboxr currently opens, previews, verifies and extracts archives.

Which permissions does it need?

It has no internet permission. The only permission it declares is the one that lets it install XAPK and split APK packages, and Android asks you to approve that before the first install.

Which Android versions are supported?

Android 7.0 (Nougat) and later, on phones, tablets and foldables.
